# Customer Churn Prediction using Deep Learning

A deep learning-based Customer Churn Prediction project that predicts whether a bank customer is likely to leave the bank based on their personal and account information.

🌐 **Live App:** https://end-end-deep-learning-nwz7cnyjslkmej4acyoecn.streamlit.app/

💻 **GitHub Repository:** https://github.com/nanjundachitra100-del/end-end-deep-learning

---

## 📌 Project Overview

Customer churn refers to a customer leaving a company or stopping its services.

In this project, I built an end-to-end machine learning/deep learning pipeline to predict customer churn using customer information such as:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Credit Card status
- Active Member status
- Estimated Salary

The trained model predicts the probability of a customer leaving the bank.
